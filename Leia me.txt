window.prompt  -> Montra uma mensagem para receber uma informação

========TIPOS DE VARIAVEIS======
Variavel no JavaScript é escrita como var 
Podemos utilizar para string  " ", ' ' , ` ` 
Podem começar com letra ou $
Nao pode começar com numeros
Pode utilizar letras e numeros
Pode utilizar acentos e simbolos
Nao pode ter espaçoes
Nao pode ser palavras reservadas

DICAS

tente utilizar nomes coerentes

Comando typeof para verificar
